## What We Covered Today

### 1️⃣ MCP (Model Context Protocol) - Part 1
Universal standard for AI-tool integration. Think of it as "USB-C for AI."
- 5-step workflow: Discovery → Specification → Execution → Response → Feedback
- Real-world applications: enterprise data, software dev, finance
- **Why it matters:** Enables seamless AI ↔ tools/data interaction

### 2️⃣ Python Topic #5: GroupBy & Aggregating
Essential Pandas technique for data exploration before modeling.
- Group data by categories, apply functions, combine results
- Multiple aggregations: sum, mean, count, min, max, std
- **Why it matters:** Summarize data and identify patterns
