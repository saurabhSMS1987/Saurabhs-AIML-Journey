---

## 🎯 What is Day 3?

Welcome to **Applied Mathematics & Neural Network Implementation**! Today you'll learn how mathematics powers machine learning and implement your first neural network with practical techniques for training.

---

## 📚 What You'll Cover

### Topic 1: Linear Algebra Applied to Machine Learning

**Key Concepts:**
- Systems of linear equations in ML problems
- Singular vs non-singular systems
- Linear regression formulation
- Multiple inputs and outputs
- Real-world ML applications (Netflix, autonomous vehicles, medical diagnosis)

**Time:** 45-60 minutes

---

### Topic 2: Deep Learning Fundamentals (Binary Classification)

**Key Concepts:**
- Binary classification problems (cat vs not cat, spam vs not spam)
- Logistic regression foundation
- Sigmoid activation function
- Forward & backward propagation
- Gradient descent optimization
- Vectorization for efficient computation

**Time:** 60-75 minutes

---
